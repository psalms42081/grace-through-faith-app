# Grace through Faith — Bible Study App

## Overview
A mobile-first Bible study app for all Christian ministries, featuring a "4-Layer Study Model" (Text, Context, Historic Voices, Application). The project aims to provide an immersive and comprehensive Bible study experience with AI-powered content generation and offline capabilities. It incorporates features like a Kids Club, devotional plans, prayer journaling, and a deep, YouVersion-inspired dark mode.

## System Architecture
The application is built with a mobile-first approach using **Expo (React Native)** for the frontend, **Express.js** for the backend, and **PostgreSQL** with **Drizzle ORM** for the database. **TanStack Query** manages server state with offline persistence via AsyncStorage, and React context handles shared UI state. **Server structure:** All 7 AI generation functions (word study, context, commentary, application, study guide start/respond, verse map, chapter context) are extracted into `server/services/ai-engine.ts` (~420 lines). `server/routes.ts` (~1,950 lines) handles Express routing, DB operations, and caching, calling ai-engine functions on cache miss.

**UI/UX Decisions:**
- **Color Scheme:** Deep dark mode (`#050507` near-black) for an immersive experience, with a warm gold accent (`#C9933A`). Kids Mode uses a distinct palette.
- **Typography:** Lora (serif) for scripture and headings, Inter (sans-serif) for UI text.
- **Icons:** Ionicons from `@expo/vector-icons`.
- **Design Philosophy:** Borderless design, YouVersion-inspired immersive dark theme, with a focus on readability and clear information hierarchy. The Bible reader features a centered book name, large chapter number, and continuous prose with inline superscript verse numbers. **Premium typography:** Lora at fontSize 21 with lineHeight 34 (1.6 ratio) for optimal readability. **Smart Selection:** tapping a verse dims surrounding text to 0.3 opacity while the focused verse stays at full opacity; focus clears via `useFocusEffect` with 400ms delay on return from the verse actions sheet.
- **Onboarding:** A 4-page swipeable welcome flow for first-time users.
- **Kids Club:** A dedicated section with KidsModeContext for age-appropriate content and progress tracking, including quizzes and stories.

**Technical Implementations & Feature Specifications:**
- **4-Layer Study Model:** Integrates Bible text (KJV, ASV, WEB), historical context, classic commentaries, and application-focused content (reflection questions, prayer prompts, journaling).
- **AI Integration:** OpenAI's gpt-4o-mini generates on-demand context, commentary, application, AND word study data for any Bible chapter/verse, all cached to the database. All study tools auto-generate when first viewed — no manual "Generate" button needed. Word study (`/api/strong/generate`) creates Strong's Concordance-style Greek/Hebrew analysis for any verse on-demand.
- **Text-to-Speech (TTS):** Uses OpenAI's gpt-audio model via a server-side API (`/api/tts`) with multiple voice options (Nova, Shimmer, Alloy, Echo, Onyx). `expo-speech` serves as a device fallback. Playback is handled by `expo-av`.
- **Offline Support & Proactive Prefetch:** React Query persistence via AsyncStorage ensures an offline-first experience with a 30-day garbage collection time. **Proactive background fetch:** when a chapter opens, the app immediately prefetches chapter context, context cards, commentary, verse maps (first 5 verses), and Strong's word study (first 5 verses) via `queryClient.prefetchQuery`. A ref guard (`prefetchedRef`) prevents duplicate fetches on re-renders. All prefetched data persists to AsyncStorage automatically, so study layers render instantly with no loading spinners — even offline.
- **Search:** Keyword search with highlighting and reference parsing (e.g., "John 3:16").
- **Real Commentary API:** Uses HelloAO Bible API (bible.helloao.org) for real public domain commentary from Matthew Henry, Adam Clarke, Jamieson-Fausset-Brown, and John Gill — replaces previous AI-generated commentary. No API key required.
- **Socratic AI Study Guide:** Interactive guided study using the Inductive Method (Observe, Interpret, Apply). AI acts as a seminary tutor — asks probing questions, never gives answers directly. Chat-like UI with phase progress indicator. **Persistent sessions with resume:** navigating to the study guide for a verse checks for an active (non-completed) session and restores the full conversation history immediately. Shows a "Session resumed" banner with a "Start Fresh" option to close the old session and begin anew. Sessions stored in `study_guide_sessions` table. Endpoints: `GET /api/study-guide/active?verseReference=&userId=`, `POST /api/study-guide/start` (with `forceNew` flag), `POST /api/study-guide/respond`, `POST /api/study-guide/complete/:id`, `GET /api/study-guide/sessions`, `GET /api/study-guide/session/:id`. Screen: `app/study-guide.tsx`.
- **Visual Verse Mapper:** Interactive verse breakdown screen that "explodes" a verse into its components — original language words (Strong's Concordance), AI-generated cross-references, and historical context. Expandable sections with word cards, cross-reference navigation, and context snippets. Data cached in `verse_map_cache` table. Endpoints: `GET /api/verse-map/:verseId`, `POST /api/verse-map/generate`. Screen: `app/verse-map.tsx`.
- **Strong's Concordance:** 14,220 entries (8,673 Hebrew, 5,547 Greek) in `strong_entry` table with full definitions, transliterations, pronunciations, KJV usage, and derivations. Searchable via `GET /api/strong/search?q=&language=`. Concordance search mode in Word Study tab.
- **Verse Actions:** Tapping any verse in the chapter reader opens a verse actions sheet (`app/verse-actions.tsx`) with: Copy, Highlight, Bookmark, Words, Context, Voices, Verse Map, and Guided Study buttons.
- **User Features:** Notes, highlights, bookmarks, prayer journal (full CRUD with category filtering and answered/active toggle), and reading history with streak tracking.
- **Devotionals:** Browser for various devotional plans, enrollment, daily reading, and progress tracking.
- **4D Scripture Context Panel:** Floating compass button in the chapter reader that expands to show AI-generated contextual data for the current chapter — locations, timeline events, key figures, and cultural insights. Tabbed interface (Places, Timeline, Figures, Culture). Data cached in `chapter_context_cache` table. API: `GET /api/chapter-context/:bookId/:chapter`. Generates + caches on first view. **Haptics & animation:** FAB pulses with a Reanimated scale bounce + shadow glow when context data arrives (while still collapsed). Haptic feedback via expo-haptics: `selectionAsync` on verse tap, `impactAsync(Medium)` on study layer launches, `notificationAsync(Success)` on context load.
- **SDA Doctrinal Studies:** Dedicated screen (`app/sda-studies.tsx`) with all 28 Fundamental Beliefs as expandable cards. Category filtering (God, Humanity, Salvation, Church, Christian Life, Last Things). Each belief shows summary, key scriptures (tappable to navigate to reader), and external EGW Writings link. Entry point on Discover tab.
- **Young Adults Section:** Third age group (`young_disciples_plus`) in Kids Club for teens 13-17. Two collections ("Faith & Identity", "Heroes of Conviction") with 8 stories total. Longer narratives, discussion questions, and teen-relevant themes. 24 quiz questions. Toggle button added to kids-stories screen.
- **Maps & Timeline:** Interactive maps with locations linked to verses and a timeline of biblical events.
- **Christian Music:** Dedicated music section with Worship & Praise, Classic Hymns, Gospel, Instrumental, Contemporary Christian, and Kids categories with external links. Content shuffles each session for freshness.
- **Family & Faith:** Family-focused Christian content from diverse voices (Joel Osteen, Joyce Meyer, Tony Evans, Charles Stanley, T.D. Jakes, Priscilla Shirer, Rick Warren, Lysa TerKeurst, Doug Batchelor, 3ABN, and more). Content shuffles each session.
- **Enhanced Topics:** 12 topic pages with curated media from diverse Christian speakers/artists. Speaker avatars (colored initials) identify each source. Content order shuffles each session.
- **Speaker Avatars:** Colored circular avatars with initials (constants/speakers.ts) used across Topic, Family, and Music screens for visual speaker identification.
- **Home Screen (YouVersion-caliber redesign):** Immersive photo-backed Verse of the Day card with nature photos from Unsplash rotating daily, dark gradient overlay for readability, action buttons (heart, share, bookmark). Weekly streak calendar (S-M-T-W-T-F-S dots) with Perfect Weeks badge. Continue Reading card with play icon. Side-by-side guided content cards (4-Layer Study, Prayer Journal). Devotional plan progress card. Horizontal-scrolling Featured Plans with gradient cover art. Backend endpoint `/api/reading-streaks/weekly` provides weekly calendar data and Perfect Weeks count via SQL aggregation.
- **Growth Analytics Dashboard:** Profile tab ("You") includes a Growth Analytics section showing: Deep Study minutes (aggregated from Socratic session durations), Greek/Hebrew Words mastered (distinct Strong's entries from user-read chapters), and Socratic session count. Below that, a **Bible Knowledge Map** heatmap renders all 66 Bible books as an SVG grid (11 columns × 6 rows) using `react-native-svg`. Books are colored by reading depth: untouched (dark/muted), partially read (light gold), mostly read (medium gold), fully read (bright gold). Tapping a block shows a tooltip with book name and chapters-read fraction. Legend shows OT/NT counts and a color depth scale. API: `GET /api/analytics/growth?userId=guest`.
- **Navigation:** 5-tab layout (Home, Read, Plans, Discover, You/Profile) — following YouVersion's structure. Plans tab has Find Plans/My Plans sub-tabs with category filter chips and plan grid. Profile tab shows avatar, stats (streak/longest/perfect weeks), weekly calendar, Growth Analytics, Bible Knowledge Map heatmap, badges (earned/unearned), recent activity feed, and quick links to Prayer Journal, Music, Family, Maps, Timeline. Search tab route preserved for deep-linking but hidden from tab bar. Study tab also hidden. Discover tab shows popular passages, topic grid, music, family, prayer journal, maps, and timeline.
- **Illustrations:** AI-generated watercolor illustrations enhance visual content.
