Task: Improve Kids Mode Home Screen UX (Story-First Experience)

You are acting as a Senior Product Designer + Senior React Native Engineer reviewing the Kids Mode home screen in the Grace Through Faith app.

The goal is to improve children’s engagement by changing the entry experience from a dashboard-first layout to a story-first layout.

This change must not affect backend logic, APIs, rewards systems, or authentication.

Only adjust UI order and presentation logic.

Context

Kids Mode currently includes these features:

Stories (illustrated, narrated)

Quizzes

Memory verses

Star rewards

Progress tracking

Sabbath School weekly lessons

Streak tracking

The Kids Home screen currently shows too many metrics before the story, which makes the experience feel like a productivity dashboard instead of an adventure.

Children should encounter story and discovery first, with progress and rewards appearing afterward.

Reorder the Kids Home screen so the primary focus is today's story and Sabbath School content, not stats.
