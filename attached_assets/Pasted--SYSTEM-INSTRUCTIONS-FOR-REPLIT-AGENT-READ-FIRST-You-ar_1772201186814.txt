GOAL
Build a mobile-first Bible study app for all Christian ministries:
- Scripture-first
- Original-language tools (Hebrew/Greek via Strong’s initially)
- Ancient Holy Land maps + timelines + illustrations
- Historic public-domain commentary (Matthew Henry, JFB, etc.)
- Modern structured study layers (Context + Application)
- Daily devotional plans customized to the user (privacy-first)

NON-GOALS
- No polemics / “which denomination is correct”
- No rehosting copyrighted modern commentaries without license
- No “AI pastor” (AI is excluded for now)
- No denomination mode in Phase 1 (denom “Perspectives” only Phase 2)

------------------------------------------------------------
1) REPLIT-FRIENDLY TECH STACK
Frontend: Next.js (App Router) + TypeScript, Tailwind CSS, Zustand (UI state), TanStack Query
Backend: Next.js API routes, PostgreSQL + Prisma
Search: Postgres FTS (Full Text Search) via GIN indexes for fast performance.
Offline: PWA service worker, IndexedDB (for caching today's devotional + viewed chapters)
Deployment: Replit Deployments

------------------------------------------------------------
2) PRODUCT PHILOSOPHY: THE “4-LAYER STUDY MODEL”
Every passage is presented in layers. 
UX RULE: Use a "Progressive Disclosure / Bottom Sheet" UI. The Bible text (Layer 1) takes up the main screen. When a verse is tapped, Layers 2, 3, and 4 slide up from the bottom in a drawer/tabbed interface.

LAYER 1 — TEXT: Bible text (KJV), Cross refs, Word study (Strong’s)
LAYER 2 — CONTEXT: Historical notes, Timeline anchors, Geography & maps
LAYER 3 — HISTORIC VOICES: Classic commentaries (Matthew Henry, JFB)
LAYER 4 — APPLICATION: "Then/Now" bullets, reflection questions, prayer prompt, user journaling.

DEVOTIONALS MUST USE THIS SAME MODEL in a “daily” format.

------------------------------------------------------------
3) DENOMINATION POLICY
A) Neutral tone ("interprets", "teaches"). No polemics.

C) Implementation: 
   - Phase 1: NO denomination mode.

D) Devotionals: Strictly Christ-centered, non-sectarian. 

------------------------------------------------------------
4) MVP FEATURES (PHASE 1: FREE)
A) Reader (KJV): Book -> Chapter -> verse list. Offline caching.
B) Search: Reference parsing (“John 3:16”) and Keyword search.
C) Word Study (Strong’s): Tap verse word -> Strong’s entry (id, lemma, gloss).
D) Context Cards: Book & Chapter context.
E) Maps (Basic): Ancient Holy Land locations linked to verses.
F) Timeline (Basic): Curated events linked to verses.
G) Historic Commentary: Excerpts from PD sources (Henry, JFB).
H) Application Layer: Then/Now bullets, questions, user journaling.
I) DAILY DEVOTIONAL PLANS:
