Implement the following changes:

### A. Reduce arrow opacity

```

```

When user taps screen or scrolls:

```

```

### B. Move arrows slightly inward

Add spacing so arrows do not hug the screen edge.

Example:

```

```

### C. Use soft circular background

Instead of arrows floating directly on the image, place them in a subtle circle:

```

borderRadius: 28
padding: 10
```

This improves visibility on bright images.

---

### D. Hide arrows on first and last scenes

If scene index is 0:

```
hide left arrow
```

If last scene:

```

```

This prevents useless navigation indicators.

---

### E. Allow swipe navigation

Ensure users can still swipe:

```

swipe right → previous scene
```

Arrows should **support but not replace swipe navigation**.
